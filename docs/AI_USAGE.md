# AI-assisted development

Codex assisted with planning, implementation, tests, refactoring and documentation. The human requirements and repository rules define scope; source code and executed checks establish behavior. A Git author identifies the commit author, not which person or model wrote an individual line. Failed drafts are not necessarily retained in Git, so the examples below describe corrections recorded during AI-assisted development without inventing line-level attribution.

## Tools and their roles

| Tool                                                  | Observed use                                                                                                                                            | Limits                                                                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Codex and read-only review agents                     | Small task implementation and independent review of access, transactions, components and documentation.                                                 | A proposed change still needs review and executable verification.                                               |
| Graphify                                              | Local source/import maps in [P02-06](evidence/P02-06.md) and [P02-12](evidence/P02-12.md).                                                              | Maps aid navigation; source remains authoritative.                                                              |
| ast-grep                                              | Structural source queries recorded in [P00-17](evidence/P00-17.md).                                                                                     | Matches still require source/context review.                                                                    |
| Serena                                                | Local TypeScript setup/indexing in [P00-17](evidence/P00-17.md).                                                                                        | The existing MCP process did not reconnect successfully in that task; setup is not evidence of live symbol use. |
| Gitleaks                                              | Redacted current-file secret checks in [P00-17](evidence/P00-17.md).                                                                                    | A clean scan does not establish application security.                                                           |
| React Doctor                                          | Advisory component review in [P09-02](evidence/P09-02.md), [P11-03](evidence/P11-03.md), [P27-01](evidence/P27-01.md) and [P28-04](evidence/P28-04.md). | Static findings complement browser tests; an unavailable score is not a perfect score.                          |
| Jest, Node tests, Supertest, Playwright and Storybook | Domain, real-PostgreSQL API, browser and component verification; each task records actual results.                                                      | Existing tests alone are not evidence that a new revision passed.                                               |
| OpenAPI export and Hey API                            | Reproducible typed client generation and drift checks.                                                                                                  | Generated code is not hand-edited; source schemas/controllers own the contract.                                 |

See [AI_TOOLS.md](AI_TOOLS.md) for local commands and configuration. Graphs, local reports and tool state remain ignored; they are not published as application assets.
