## Work contract

Add three task-write endpoints with shared schemas/DTOs and generated clients. Every write locks the workspace, rechecks actor/list access and expected revisions, validates the complete result against current statuses/fields and visible current-member assignees, and atomically persists task/data revisions plus outbox intent. Preserve omissions, clear explicit nullable/field values, use whole-array assignees, append creates/status changes to the column, preserve no-op revisions and archive history.

Add a separate member query for assignableToListId, using the same central ancestor policy as assignment validation and filtering before cursor limit. Bind the filter into the member cursor. Do not widen workspace-list query acceptance. Task mutations advance dataVersion only; configuration changes retain their existing helper. Creation has an explicit event shape, and updates carry a nonempty sanitized change summary.

Files: task/event/member contracts, task/access/member database repositories and task event helper, task service/controller/DTO and member-query integration, real API/database tests, generated artifacts, documentation. First observe missing write routes with a behavioral API test. No moves/reordering endpoint in this task.

## Regression observations

- Initial POST task request returned404 before the write routes existed; assignable member query returned400 before its contract/repository path was introduced.
- A retained-assignment regression failed because replacing assignees recreated an unchanged join row and reset its audit times. The fix changes only added/removed memberships.
- Undefined-only edits were accepted by the first schema; a regression now requires at least one defined change. Event summaries have the same rule.
- Reversed assignment order exposed an incorrect error index after sorting. Validation now keeps request order and sorting is limited to persistence/response representation.
- With application time one day ahead, creation used a future audit timestamp. Creation now supplies PostgreSQL time, so immediate archive remains valid.
- The first full gate run exposed nullable-union OpenAPI output rejected by Spectral and a Supertest cleanup request created before awaiting a configuration lookup. Nullable alternatives now each carry their type; the test resolves its prerequisite before constructing the request. Neither check was suppressed.
