# P00-15 — Parallel CI on free public-repository runners

Date: 23 October 2026. Requirement: R98; preserves independent release and preview gates.

The verification job is now a five-lane matrix: build, lint, tests, types and formatting. Every lane uses an unfiltered root command and therefore covers all applicable workspace tasks through Turbo. Lanes have no dependency on each other, and fail-fast is disabled. Docker acceptance runs alongside them. Release publication still needs the complete matrix and Docker success; preview deployment still needs publication.

All jobs use standard `ubuntu-24.04` runners. Public visibility was confirmed for `ashvir99260/flowboard` through GitHub. Entry jobs skip private repositories; dependent release/deploy jobs consequently do not start there. No paid runner, external cache, organization subscription or billing setting was added. Current GitHub documentation confirms standard hosted runners are free for public repositories: <https://docs.github.com/en/actions/reference/runners/github-hosted-runners#standard-github-hosted-runners-for-public-repositories>.
