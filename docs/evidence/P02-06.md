# P02-06 — Feature modules, common infrastructure and split tests

Date: 23 October 2026. State: complete. Requirements: R116/R117; preserves R20, R21, R91 and R115. This record belongs to the task commit; resolve its revision through Git history.

## Delivered scope

AppModule composes AuthModule, PlatformModule and CommonModule. Feature modules own their DTOs and lifecycle providers; CommonModule registers the shared error filter and Zod validation/serialization. Common folders contain reusable decorators, error/empty-query DTOs, errors, filters, Swagger helpers, application/Redis configuration and the reused boolean-setting parser. Auth-specific configuration stays in `auth/config/`. Prisma and shared Zod schemas retain their package ownership.

API tests are split into six unit suites, five HTTP integration suites and one Node startup suite. Helper-only `test/common/` holds disposable infrastructure/application factories, shared auth fixtures and cleanup. Each integration suite owns its own services. Auth prerequisite data is initialized before cases, and the database-outage case runs in a separate suite. Cleanup is memoized across owners, including rejected cleanup, so a failed app startup cannot tear down one runtime twice.
