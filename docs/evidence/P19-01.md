# P19-01 MUI Data Grid task lists

Date: 2026-10-25. State: complete. Requirements: R23, R69, R70, R134, R139, R140. Dependency P18-01 is complete.

Scope/design: D144. Shared presentational Community grid, existing cursor/URL data ownership, visible pagination over loaded rows, keyboard/focus and rem scaling. No API or persistence changes.

## Implementation and review

Pinned MUI X Data Grid Community 9.16.0 and its compatible MUI System peer 9.5.0 in UI. TaskTable retains its public props, stable task IDs, title actions and metadata/custom-field renderers. Grid-local sorting/filtering is disabled; web still owns URL state and cursor requests. The visible paginator pages already-loaded rows, including more than 100, without offset requests. The observed one-rem measurement preserves font scaling for the grid's numeric geometry API.

Two independent read-only reviews found no blocking defects in pagination, keyboard/focus, SSR/rem measurement or API ownership. Added the suggested append-on-a-later-page regression. Documentation records the Community pagination tradeoff and the UI/web boundary.

## Observed failures and corrections

- The Node behavioral test first failed because the prior table had no grid role. It passes with the real installed Data Grid package, without a CSS shim.
- The append regression first failed because the fixture lacked an append action. The controlled story now starts with 55 rows, selects page two, appends through 105, preserves Task 051, reaches Task 105 and resets to two rows.
- Type checking caught a Playwright-only query option used in Testing Library stories; removed the unsupported option. Lint caught object-key ordering in two browser selectors; corrected the selectors. The final type/lint checks pass without disabling rules.
