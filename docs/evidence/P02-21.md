## Findings corrected during verification

- The first temporary copy included the local pnpm store. Stopped only that test process, deleted its own temporary directory and excluded caches from subsequent copies.
- Docker's disk reached 99% usage during an early development build. Removed six unused images and three large cache records created by this task only; no database volumes or unrelated images/cache were deleted. Narrowed development ownership changes to exclude node_modules and reduced duplicate image layers.
- A clean source copy has no generated Prisma directory. Docker cannot mount tmpfs beneath a read-only parent without an existing mount point. README now creates the ignored directory once; the test creates it empty and asserts that it stays empty while Prisma generates inside the container.
- Shared-library rebuilds exposed a Turbo filesystem-watcher exit while Prisma replaced generated directories. Development-only on-failure restarts recover the watcher; the full live-edit check passed after this change. Next's watcher remains non-interruptible for normal refreshes. Web development includes OpenSSL for its transitive Prisma build.
- One parallel host-check run read an API module while another check was rebuilding it. The isolated lint retry passed. Final host build/lint/type/contract checks run sequentially to avoid shared-output races.
