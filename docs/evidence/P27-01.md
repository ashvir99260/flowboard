## Scope and design

D153 selects 3.6rem desktop controls and filled metadata from the shadcn references, with 4.4rem coarse-pointer targets. Keep MUI, outlined native inputs, content-driven multiline controls, semantic tokens, HSL/rem and existing data contracts. Tests use the existing public UI and browser seams; screenshots verify actual rendering in both themes.

The theme explicitly supplies small outlined defaults, input padding/line height, full borders and semantic palette mappings. Shared status and selected-option chips fill with persisted colors and choose the higher-contrast black/white token for their text; priorities use semantic fills. Unsupported colors and mixed selections retain neutral fills. The development playground and Storybook show the same exported components as the application.
