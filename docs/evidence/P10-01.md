## Work contract

Provide administrator status settings for workspace/space/folder/list scopes. Load each verified ancestor's local rows at one configuration revision. Preview effective statuses with the shared resolver; show local, inherited and hidden identities without changing canonical IDs. Edit one status at a time, including explicit inheritance/visibility values, add definitions and remove local overrides. Preserve drafts on failed saves and require explicit recovery from stale configuration. Members have no configuration controls, and direct access remains forbidden by the API.

Files: web status configuration feature and settings route, sidebar navigation, workspace-scoped configuration settlement notifications, pure/browser fixtures and tests, playground example, decisions/task/matrix/README/evidence.

Failure cases: mixed/foreign configuration, missing required categories, in-use hide/delete, null versus omitted overrides, duplicate keys, stale writes, sibling isolation, role denial, dirty scope changes, keyboard/focus and target widths. Use generated API operations and the existing shared schemas; no new endpoint is needed.

Gates: red/green pure and browser checks; root build/lint/typecheck/format/test; existing real-Postgres status suites and browser acceptance; read-only review. No completion claim until those gates pass.
