## Work contract

Five scoped field endpoints use shared contracts, typed Nest DTOs, the central permission policy and tenant repositories. Local configuration is admin-only; visible members read a list's resolved schema. Writes lock the workspace, recheck access and configuration revision, validate every affected live scope/task, and record one configuration outbox event. No-op patches preserve audit timestamps and revisions. No migration is needed.

Files: contracts field configuration schemas/events, database field repository/shared scope navigation, API fields module/permission integration/error mapping, generated OpenAPI/client, colocated integration tests and documentation.

Failure cases: foreign/mismatched owners, member configuration access, private/denied lists, duplicate keys, malformed options/types, stale revisions, invalid required/type/option changes, destructive removals and transaction rollback. Gates G01–G08 apply.
