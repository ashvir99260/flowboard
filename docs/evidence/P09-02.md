They cover pointer moves, keyboard reorder/cancel/empty-column entry, button moves persisted after reload, 403 rollback with preserved form values, required-field correction/focus, explicit source-only clearing, duplicate submit protection, an overlapping 409 that preserves another saved move, navigation during a pending cross-list move, and 320px/reduced-motion controls. The fixture is test-only; existing real PostgreSQL backend move suites remain required.

Observed/fixed issues: dynamic Controllers initially displayed source values but registered undefined values; controls now have full typed defaults. RHF refs now target native inputs. Keyboard tests wait for drag state and the library's deferred listener registration instead of racing immediate key events. The move form was split into destination loading and a typed form using shared validation. The sidebar and list picker reuse the same complete, validated visible-tree hook.

Independent review found a destination-board refresh gap after navigation and an optional-status mismatch. Each mounted affected board now observes scoped MutationCache settlement and starts a whole new generation. The UI command explicitly requires its resolved status. The corrected navigation regression was observed failing with that refresh disabled, then the source was restored before rebuilding; its result is recorded under `/private/tmp/flowboard-p0902-settlement-proven-red.log`.

Two further review findings were reproduced before fixing them. The duplicate-submit regression initially lost its disabled Saving button while the first request was gated. A synchronous form guard now makes only that request own busy state; Save, Cancel, destination, status and placement stay disabled. The outside-board pointer regression initially moved the second card to the first position when released over the heading. Pointer collision detection now requires an actual containing target; keyboard distance-based navigation is unchanged. The cancellation case also runs with reduced motion and checks focus, unchanged order, no write request and reload persistence. Both regressions pass in the final 17-case focused run.

React Doctor scanned 14 changed source files and reported one “mutation without cache invalidation” warning; its remote score service was unavailable. That heuristic does not recognize the scoped settlement observer in `use-board.ts`. Whole-board generation refresh is intentional; adding per-page invalidation would break signed cursor chains. No lint rule or test is disabled. Independent read-only follow-up reviews found no further blocker in the two fixes.
