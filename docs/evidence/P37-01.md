# P37-01 Stable drag placement and completion feedback

State: implementation complete; final acceptance pending. Requirement: R172; preserves R64/R162/R166.

Local placement state updates synchronously with the drop. A completed placement is folded into a retained, previously validated board presentation while fresh cursor pages are read. New mutations and pagination wait for reconciliation; keyboard focus returns when controls become available. Task-data invalidations may use this bridge; workspace/configuration/resync and failed/invalid reads discard it. Generation/epoch checks prevent earlier reads from reviving cleared content.

Saving/completion text no longer shifts the board. One success toast follows the validated response, distinguishing a reorder from a move. Failed requests retain their error feedback and roll back only their own projection. Toast registration now survives StrictMode, and reduced-motion mode preserves the hidden dismissal clock rather than expiring messages immediately.
