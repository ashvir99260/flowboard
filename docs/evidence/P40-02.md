# P40-02 — Stable initial loading skeletons

Date: 26 October 2026
State: in_progress (implemented; full integration verification pending)
Requirements: R180

## Implemented behavior

Shared MUI skeletons cover the workspace shell, navigation, board, table and task drawer. Shapes use the existing theme, contain no fake controls and stop animating with reduced motion. One loading status sits outside each decorative busy subtree. The table reserves the same height as the real grid; drawer fields follow the real vertical layout.

Initial table loading uses a skeleton. Later sort/filter queries keep the grid and its filter panel mounted, clear rows and use the grid's loading overlay. Errors clear that initialized state. Existing filter-focus regressions caught the initial implementation unmounting the grid, and the denied-page test caught an error/ready render loop; both were corrected without changing those assertions.
