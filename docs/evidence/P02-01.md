# P02-01 — Workspace-aware signup and login

Date: 23 October 2026. Requirements: R28–R33, R35 (signup/login and initial-session portions).

Signup and login use strict shared schemas, Nest DTO/response decorators, generated OpenAPI/client code, Argon2id and real PostgreSQL sessions. Signup atomically creates a workspace, admin membership and default status identities/display rows. A default-on guard validates signed access tokens against the current DB family/workspace/membership. D82 records the runtime settings and security policy.
