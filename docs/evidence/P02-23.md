# P02-23 — Local Swagger authentication

Date: 23 October 2026. State: complete. Requirement: R133.

## Work contract

Fix local configuration so Swagger's actual browser Origin is explicitly allowed alongside the web origin. Preserve strict rejection of missing/unlisted origins, production configuration, credentials and stored data. Test the shipped local configuration and real HTTP authentication lifecycle, then verify browser execution and root/Docker gates. D102 records the choice.

## Reproduction

At `http://localhost:3001/docs`, expanding login, selecting Try it out and Execute returned 403 with `ORIGIN_REJECTED`. The browser sends its own `http://localhost:3001` Origin even though Swagger's generated curl/header input displays `http://localhost:3000`. Both examples and the Compose default allowed only port 3000.

## Acceptance evidence

- **pass — red configuration tests:** `node --test test/bootstrap/compose-origins.test.mjs` failed for the missing default Swagger origin and incorrect custom-port defaults; the explicit override case already passed.
- **pass — red HTTP regression:** the new `swagger.integration.spec.mjs` failed with 403 instead of 200 at login from `http://localhost:3001`, matching the browser failure. Both local example assertions also failed because their allowlists omitted the API origin.
- **pass — corrected configuration:** all three Compose tests pass for default ports, custom ports and an explicit allowlist. Root/API examples pass their two-origin assertions.
- **pass — real HTTP lifecycle:** isolated PostgreSQL/Redis test signs up from the web origin, signs in from the Swagger origin, rotates its httpOnly cookie and logs out. Missing, unlisted-local and hostile origins receive 403 without consuming the valid refresh credential or setting a cookie. Four focused auth/config tests pass.
- **pass — live browser:** updated only AUTH_ALLOWED_ORIGINS in ignored root/API env files, retaining their other values and mode 0600; recreated only the API service. Swagger Execute now returns login 200, refresh 200 and logout 204 using the local demo account. Screenshot `.ai-local/p0223/swagger-logout.png` contains the logout result and is ignored; live tokens were not printed or committed.
