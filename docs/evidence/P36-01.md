# P36-01 Searchable selections

State: implementation complete; final acceptance pending. Requirement: R170.

Shared `SelectionInput` uses MUI Autocomplete for single and multiple values. The forms adapter and custom-field selects delegate to it, so task assignees use the same searchable chips. Typed text never creates an option; stable IDs, explicit null/false/zero, disabled values and unavailable selections remain intact. Clear actions use one accessible icon.
