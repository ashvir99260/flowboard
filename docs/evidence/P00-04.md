# P00-04 — Pruned Docker images and five-service Compose

Date: 23 October 2026. Status: complete. The containing commit identifies this verification revision.

## Scope

Added separately buildable API, web and worker Dockerfiles, each using `turbo prune --docker`, pinned Node image content and non-root runners. API/worker use pnpm 12.15 production deployment; Next uses standalone output with copied browser assets. Compose adds health-gated PostgreSQL and Redis, private datastore ports, persistent volumes, local environment examples and an optional localhost port override.

The new delivery plan captures the user's independent-release and hosted-Neon request. P00-05/P00-06 own that implementation. R24–R27, R95 and R96 have foundation evidence here; broader readiness, initialization and release requirements remain open for their later tasks.

## Failing-first observations

- The initial `scripts/check-compose.mjs` execution failed because Compose did not exist.
- The first full stack check exposed a stale random host port after restart/recreation. The check now resolves the published address again.
- A custom `POSTGRES_DB`/`POSTGRES_USER` test failed because probe credentials inherited host settings. Test configuration now supplies its own fixed local-only values; the same custom-setting configuration check passes.
- The standalone web test returned 404 for a referenced JavaScript asset. The build now copies browser assets into standalone output, and the same HTTP asset test passes.
- Review tightened web health to 2xx/3xx and checked isolated cleanup, production dependency packaging and non-root execution.
