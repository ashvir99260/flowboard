# P00-08 — Continuous deployment after verified releases

Date: 23 October 2026. Requirements: R98; preserves R94–R97. Implementation/local verification complete. Live provider acceptance remains P00-09.

## Delivered

The existing PR CI and independent main publisher now precede a separate, serialized production deployment job. It runs only on main with `CD_ENABLED=true`, reads published release manifests, checks source ancestry and current main, and reconciles the latest per-app release. Provider versions already current are read-only skips. This recovers missed releases when a later unrelated commit supersedes an interrupted run.

Northflank receives an immutable external image digest without overwriting replica count, runtime variables or ports. Vercel stages the released commit, waits for readiness, rechecks current main, then promotes and verifies production routing. Credentials/target IDs are documented in CI_CD.md; Vercel automatic Git deployments are disabled in the app config. Neither provider accounts nor database resources were created.
