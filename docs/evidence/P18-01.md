# P18-01 UI component Storybook

Date: 2026-10-25. State: complete. Requirements: R23, R134, R139. Dependency P17-01 is complete.

Scope and design: D143; UI-only stories/configuration, Turbo commands and tests, development-output/release isolation. No app API, persistence, deployment or global agent setting changes.

## Implementation and review

Pinned Storybook 10.6.3 with React/Vite, Docs, Accessibility and Vitest addons. The browser preview reuses the existing MUI theme without the Next SSR wrapper. Six typed story files provide 24 examples, including numeric drafts, required false, unavailable options, tree/card/table actions, cancellation/focus return and modal toasts. Story-only source remains outside library output and does not contribute to app releases; runtime UI edits still release web.

Two independent read-only reviews covered component props, fixture validity, theme separation, Controls, dependency boundaries, Turbo ordering, CI/browser versions and release fingerprints. Corrected a nonfunctional open control by making the trigger-managed example explicit. No remaining concrete issues were reported.

## Observed failures and corrections

- The release regression first failed: adding only Storybook files incorrectly proposed a web release. Narrow UI-only exclusions now pass that regression and preserve runtime-file release detection.
- The first browser run could not open its local test server in the restricted environment. The permitted browser run then exposed two assertions before entrance animations finished. Condition-based visibility checks fixed them; no arbitrary delays or disabled checks.
- Strict typing exposed four story-adapter prop/query mismatches; they were corrected against the real component APIs. Root lint exposed ordering of new Turbo keys; its configured safe sorting fixed those entries without sorting package.json.
