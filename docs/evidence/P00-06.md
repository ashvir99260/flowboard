# P00-06 — CI, independent image publication and hosting guide

Date: 23 October 2026. Requirements: R94–R97. Status: implementation and local acceptance complete; first remote publication is tracked by P00-07.

## Delivered

The GitHub workflow validates PRs with read-only access. Main publication waits for the standard gates and Docker acceptance, serializes writers, and grants content/package writes only to the publisher. Each affected application gets an immutable version/SHA image, explicit source tag and GitHub Release with `release.json`. Upload/publication failures resume an existing draft through authenticated listing. Existing image identities and clean source checkouts are verified before image operations.

The guide documents the user's selected Vercel UI, Northflank API/worker/Redis and Neon PostgreSQL setup, provider-specific settings, server-only secrets, rollback by digest, limitations and the boundary between publishing and deployment. No account, paid plan or cloud service was provisioned.
