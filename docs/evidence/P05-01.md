# P05-01 — Pure custom-field resolution and validation

## Work contract

Continue after P04-03 (`7a07e05`, PR #13). Implement framework-free contracts and shared logic for R11/R13/R56–R58/R61. Preserve the documented full-definition precedence and distinguish missing values from explicit clearing. API writes and task moves remain later tasks.

## Plan

1. Observe a failing pure resolver fixture before implementing the first slice.
2. Define audited field/option/source/resolved contracts, validate scope paths and deterministic nearest-owner resolution with per-scope/effective caps.
3. Add failing value fixtures, then validate all six field types, required values, option identities, strict dates, Unicode and map byte/key bounds with field paths.
4. Add patch application that preserves omissions, removes nulls, validates the complete result and supports explicit source-only clearing during future moves.
5. Test duplicates, malformed input, foreign/sibling definitions, empty schemas, boundary values, input immutability and schema-valid examples/results. Run full gates, record decisions/evidence, commit and stack the PR.
