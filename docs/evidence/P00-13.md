# P00-13 — Initial hosted preview pipeline

Date: 23 October 2026. Requirements: R98; preserves R94–R97 and defers R99. Implementation verified; live acceptance remains P00-14.

## Delivered

The main-only deployment job now uses GitHub's `preview` environment and `pnpm deploy:preview`. Release selection, source ancestry checks, serialization and Northflank digest readiness are preserved. Vercel creates or reuses a preview of the released SHA, validates its metadata/target and prints its ready generated URL. No production promotion endpoint is called.

Vercel forces a new project's first deployment to production. The adapter therefore checks unfiltered project deployment history before creation and fails before a write on an empty project. It also disables automatic custom-domain assignment. The guide requires a separately reviewed real-app bootstrap in a dedicated preview-only project, without production data/credentials. No fake or deliberately failed bootstrap is introduced.

The existing production-promotion tests were superseded by preview tests because that behavior was removed. Preview coverage retains failed/cancelled/blocked builds, timeout, retry, stale-run and source identity checks, and adds URL validation, production-target exclusion, null/omitted target representations and empty-project safety.
