# P35-04 Header and global search

State: implementation complete; final acceptance pending. Requirements: R168, R169.

The shared header offers task/list search, New task, Invite, theme toggle and an account menu with initials/name/role and Sign out. Sidebar administration remains available. Search uses the generated operation, validates response pages, supports cursor loading and opens existing task/list flows. Closing the dialog clears results; workspace/resync/focus/reconnect and scoped local mutations restart from page one. Card actions move alongside the title for a more compact layout.
