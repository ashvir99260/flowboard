# P35-03 Authorized workspace search

State: implementation complete; final acceptance pending. Requirement: R169.

GET /v1/search searches active-workspace tasks and lists. The tenant repository resolves the full visible tree before parameterized SQL filtering/pagination and returns only authorized navigation fields/breadcrumbs. Signed cursors bind the caller, workspace, query, limit, type/ID position and both revisions. DTOs, OpenAPI and generated client are included.
