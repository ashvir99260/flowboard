# P40-03 — Compact workspace visual hierarchy

Date: 26 October 2026
State: in_progress (implemented; full integration verification pending)
Requirements: R181

## Scope and behavior

Shared board columns use single-row names and accessible numeric count badges. The default detailed status chip remains available for configuration previews. Cards have consistent padding, less elevation and quieter normal/low priority fills. Workspace/list board refresh actions are labelled icons; a compact mobile create action and header spacing keep the logo and actions separate.

The new shared rendering regression failed before implementation because the numeric counts were not exposed. Browser screenshots and interaction checks validate the final layout, whole-card actions and drag behavior. No domain API, status identity, permission or deployment contract changes.
