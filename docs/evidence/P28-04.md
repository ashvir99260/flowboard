# P28-04 Task table row activation

Date: 2026-10-25.
State: complete.
Requirements: R153.
Commit: This record belongs to the task commit; resolve it through Git history.

## Behavior

Clicking non-interactive row content opens that row's current task exactly once. The existing title button remains keyboard accessible and receives focus before row opening, allowing drawer closure to restore focus. Modified or canceled clicks, selected row text, links, native controls and editable content are excluded. Rows are resolved against current items; removed items cannot be opened by the callback.
