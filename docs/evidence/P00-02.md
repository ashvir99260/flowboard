## Implementation and review

Shared ESLint configuration now enforces workspace ownership for imports, exports, type imports, import-equals, dynamic imports and require calls. It rejects cross-workspace relative/absolute/file-URL paths, inherited aliases, Prisma access outside database, impure contracts and web/UI HTTP bypasses. The only app-import exception is the OpenAPI scripts' explicit `@flowboard/api/spec` export. Configuration uses TypeScript's parser for JSONC and inherited aliases.

Independent review exposed absolute/file URL, computed-fetch, dynamic-require and inherited-alias bypasses. Six regression cases failed before those fixes and passed afterward. Tests assert the boundary rule's own diagnostic rather than counting parser failures. Root lint is run from the root directory so the root config is actually checked; warnings fail that lint command. The Next preset is activated when its runtime arrives in P00-03.
