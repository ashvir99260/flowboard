## Behavior

Task due dates are nullable instants normalized to UTC milliseconds. Explicit offsets are accepted; malformed, date-only, timezone-less, overprecision and out-of-range values fail validation. Generic datetime-local controls preserve fractional seconds; the task-specific adapter explicitly edits UTC and handles native minute-only values. Custom date fields remain calendar days.

The checked-in migration converts old DATE values to midnight UTC independently of session timezone. It updates only historical due-date paths in task.updated outbox payloads so queued references remain consumable. Task versions, task audit dates, nulls and unrelated custom/event data are preserved. API and worker need coordinated upgrade; old date-only clients/cursors are rejected.
