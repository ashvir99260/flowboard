# P39-04 — Hosted Swagger routing and runtime document

Date: 26 October 2026
State: complete
Requirements: R175; D172

## Outcome

Swagger remains opt-in. The runtime-only document uses validated `API_DOCS_BASE_PATH`: `/` for direct/local access, `/api` behind the web proxy. The two existing health paths override this base to `/`. Canonical OpenAPI and generated clients remain unchanged. Swagger includes cookies in requests but does not persist entered authorization tokens.

Vercel routes only `/docs`, `/docs/*`, `/docs-json`, `/docs-yaml`, `/health/live`, `/health/ready` and the existing Socket.IO path directly to API. Domain `/v1/*` is still private behind the web proxy. This implementation prepares the deployment; P39-05 owns actual activation and live acceptance.
