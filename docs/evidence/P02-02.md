# P02-02 — Single-use refresh and logout

Date: 23 October 2026. Requirements: R29, R33, R35 (backend session lifecycle).

Refresh rotates the httpOnly credential under the User lock, preserving family identity, workspace and fixed expiry. Replay commits revocation for the whole family before returning401. Logout revokes the family and clears the cookie. Shared empty-body contracts, cookie security metadata and generated clients ship together. D83 records concurrency and cookie choices.
