Regression tests exercise safety already implemented in P04-02; do not manufacture failing production behavior just to make characterization tests red. Docker reported 26.07 GB of cache records removed; filesystem free space rose to 6.2 GB. Running services stayed healthy and no existing database volumes were pruned. The full suite then passed after cleanup.

An isolated empty-container experiment reproduced the leak: after the existing `docker rm --force` cleanup, its anonymous volume still existed. Test fixture cleanup now requests `--volumes` for its owned containers. A second empty-container experiment verified the corrected cleanup removes its owned volume. New real-Docker regression tests capture only their own mount IDs and assert those volumes disappear; both complete infrastructure regression tests now pass after freeing disk space. This touches test infrastructure only and does not prune existing volumes.

No new production behavior is claimed by this regression-only task.
