# P40-01 — Preserve content during routine refreshes

Date: 26 October 2026
State: in_progress (implemented; full integration verification pending)
Requirements: R179

## Implemented behavior

Board, list and workspace views retain their validated same-scope snapshot during focus/reconnect and ordinary task refreshes. A shared queue merges overlapping requests into one trailing refresh without dropping a later invalidation. Explicit configuration/workspace resets and terminal errors clear snapshots. Placement mutations retain their existing projection and rollback behavior. Background work exposes `aria-busy` without removing the current board/grid.

The first delayed-focus browser regression failed because the board disappeared. A later-page denial regression then exposed stale rows reappearing during Retry; terminal errors now clear the saved snapshot before ready-data capture. Existing permission-recovery coverage caught a queue that stayed busy after a failed pending read; failed reads now release it. None of these fixes weakens the original assertions or access checks.
