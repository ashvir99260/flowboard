## Work contract

Two read endpoints use shared schemas, typed DTOs, generated contracts and central permissions. They return built-ins, custom values and safe assignee names with both same-snapshot revisions. The existing signed cursor codec now carries task sort tuples and a query fingerprint, retaining fixed expiry and tenant/caller/list/limit/filter binding.

Manual order follows resolved statuses, task position and ID. Dates keep nulls last in both directions; priorities use urgent/high/normal/low/none rank. Typed JSONB filtering occurs before limit+1 pagination. SQL and raw persistence remain in the database package. No task mutations were introduced.
