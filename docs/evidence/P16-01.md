## Review and limitations

Independent reviews identified and resolved stale auth failures, old socket callbacks, strict old-client incompatibility and ambiguous legacy test selectors. Session actions now fence their terminal results; socket callbacks compare current credentials and subscription state; new clients negotiate metadata through a public handshake query. Existing inline assertions select the unnamed status exactly, and new tests select named notifications.

Notifications are transient UI feedback; the activity feed remains durable history. Self means the acting account, including its other tabs. No task content, actor identifier, credentials or private move destination is added to realtime messages. No deployment or external notification delivery was performed.
